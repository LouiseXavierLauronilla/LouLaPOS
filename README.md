\# EnterprisePOS



EnterprisePOS is a Windows Forms Point of Sale and Inventory Management System.



\## Project Structure



\- EnterprisePOS.Data – Database access and repositories

\- EnterprisePOS.Domain – Application entities

\- EnterprisePOS.Services – Business services

\- EnterprisePOS.WinForms – Windows Forms user interface

\- Database – SQL database scripts



\## Requirements



\- Windows

\- Visual Studio

\- SQL Server

\- .NET Framework compatible with the project



\## Setup Instructions



1\. Clone or download this repository.

2\. Open EnterprisePOS.slnx in Visual Studio.

3\. Configure the SQL Server connection in the application configuration.

4\. Execute the SQL scripts in the Database folder to create the database.

5\. Build the solution.

6\. Run the EnterprisePOS.WinForms project.



\## Database



Database creation scripts and stored procedures are located in the Database folder.
